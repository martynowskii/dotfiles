## Структура

```text
nvim/
|- init.lua
|- lua/
    |- config/
    |- plugins/
|- after/
    |- lsp/
```

---

### `lua/`
Главная папка для Lua-модулей.

### `lua/config/`
Папка для **базовой конфигурации Neovim**, не привязанной к конкретным плагинам.

### `lua/plugins/`
Папка для **подключения и настройки плагинов**.

### `after/lsp/`
Папка для **настройки lsp серверов**.
