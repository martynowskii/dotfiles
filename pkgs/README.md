# pkgs

Чужие программы, которых нет в nixpkgs. Один каталог на пакет, внутри
обычное выражение для `callPackage`:

```nix
pkgs.callPackage ../../pkgs/zaread { }
```

Отличие от соседнего `apps/` — в авторстве, а не в устройстве: там то, что
написано здесь, тут то, что мы только собираем. Если программа появится в
nixpkgs, каталог удаляется, а вызов заменяется на `pkgs.<имя>`.

| пакет | что это |
| --- | --- |
| [`zaread`](zaread/) | открывает документ в zathura, конвертируя его через LibreOffice |
