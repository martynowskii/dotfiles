# apps

Самодельные приложения — то, что написано здесь, а не настроено.

Один каталог на приложение, и в нём всё своё: исходники, тесты, README и
`default.nix`, который объявляет окружение аргументами функции. Конфигурация
хоста такое приложение только подключает:

```nix
pkgs.callPackage ../../apps/gdoc { }
```

Отсюда переносимость: каталог можно скопировать в другой репозиторий или
отдать кому-то, и он соберётся — ни один путь не ведёт наружу. Обратное
правило тоже действует: если `default.nix` приложения тянет что-то из
`home-manager/` или `nixos/`, это ещё не приложение, а модуль конфигурации,
и его место там.

Чем это отличается от соседних каталогов:

- `home-manager/`, `nixos/` — конфигурация машины и профиля;
- `nvim/`, `zsh/`, `niri/`, `noctalia/`, `vim/` — конфиги программ, которые
  написал кто-то другой;
- `apps/` — программы, которых без этого репозитория не существует.

| приложение | что делает |
| --- | --- |
| [`gdoc`](gdoc/) | рендерит doc/ppt/xls/md в PDF и открывает в zathura |
