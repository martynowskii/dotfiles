# gdoc

Открывает `.doc`, `.docx`, `.odt`, `.rtf`, `.fb2`, `.xls(x)`, `.ods`, `.csv`,
`.ppt(x)`, `.md`, `.epub` в zathura: документ рендерится в PDF здесь же, на
машине — ничего никуда не выгружается и офисный пакет не нужен.

```
gdoc отчёт.docx              открыть
gdoc -o ~/pdf/ *.docx        сохранить PDF и не открывать
gdoc -p отчёт.docx           напечатать путь до PDF в кэше
gdoc --html отчёт.docx       открыть промежуточный HTML в браузере
gdoc -f отчёт.docx           пересобрать, не доверяя кэшу
gdoc --clean                 выбросить кэш
```

## Как это устроено

Конвертер отдаёт HTML, HTML печатается в PDF, PDF кладётся в кэш
(`$XDG_CACHE_HOME/gdoc`) и отдаётся просмотрщику.

| модуль | за что отвечает |
| --- | --- |
| `gdoc.py` | точка входа |
| `cli.py` | аргументы, запуск просмотрщика, `-o` |
| `cache.py` | кэш и его атомарное пополнение |
| `renderers.py` | конвертеры форматов → разметка документа |
| `sanitize.py` | очистка разметки, пришедшей от конвертера |
| `page.py` | страница, в которую эта разметка заворачивается |
| `printing.py` | печать страницы в PDF силами headless-chromium |
| `blobs.py` | извлечение картинок из бинарных `.doc` и `.ppt` |
| `common.py` | запуск конвертеров и общие мелочи |

Разметке из документа доверять нельзя: pandoc пропускает сырой HTML из
markdown и epub насквозь, так что документ способен принести `<script>`,
`<iframe file://>` и `onerror=`. Поэтому `sanitize.py`, а chromium вдобавок
запускается без сети (`--host-resolver-rules=MAP * ~NOTFOUND`).

## Подключение

Пакет самостоятельный — все внешние программы объявлены аргументами
`default.nix`:

```nix
home.packages = [ (pkgs.callPackage ../../apps/gdoc { }) ];
```

Список mime-типов для `.desktop` лежит отдельно в `mimes.nix`, чтобы
`.desktop`-запись и `xdg.mimeApps` не разъезжались. Как это подключено
здесь — `home-manager/modules/docs.nix` и `mime.nix`.

Переменные окружения переопределяют то, что прибито к store:
`GDOC_VIEWER`, `GDOC_BROWSER`, `GDOC_CHROMIUM`.

## Тесты

```
cd apps/gdoc && python3 -m unittest discover -s tests -t .
```

Внешние конвертеры не нужны: `.pptx` читается своим кодом через `zipfile`,
а сборка проверяется на подставном рендерере.

## Чего gdoc не умеет

- `.ppt` отдаёт только текст и галерею найденных картинок — раскладки
  слайдов в бинарном формате нет;
- таблицы теряют заливку и объединённые ячейки;
- мусор вместо `.rtf` всё равно даёт «успешный» PDF: pandoc вытягивает
  осмысленное из любых байтов;
- ошибки идут только в stderr, так что неудача при открытии двойным
  щелчком ничего не покажет.
